========================================================================
RICH X CAM LIVE - WhatsApp Desktop & Calling Apps Integration Guide
========================================================================

If "RICHX CAM" or "RICHX MIC" is not showing in WhatsApp:

STEP 1: Run the Driver Registration Utility
-------------------------------------------
Right-click on:
  install-richx-virtual-devices.bat
and select "Run as administrator". This registers the DirectShow virtual 
camera and virtual audio endpoints in Windows.

STEP 2: Configure WhatsApp (Desktop or Web)
-------------------------------------------
1. Open WhatsApp.
2. Click the gear icon (Settings) -> "Audio & Video" (or "Calls").
3. Under "Camera":
   Select "RICHX CAM" (or "RICH X Virtual Camera").
4. Under "Microphone":
   Select "RICHX MIC" (or "CABLE Output / Virtual Audio Cable").

STEP 3: Start your Call in RICH X CAM LIVE
------------------------------------------
1. Launch RICH X CAM LIVE software.
2. Select your persona avatar image and appearance prompt.
3. Click "Start Video + Audio Call" (or "Start Video Only Call").
4. Make your call in WhatsApp — your converted real-time video avatar and 
   synchronized voice will stream live into WhatsApp!

Compatible Applications:
- WhatsApp Desktop & WhatsApp Web
- Telegram Desktop & Web
- Zoom Desktop Client
- Microsoft Teams
- Discord
- Google Meet / Google Chrome / Edge
- Skype
